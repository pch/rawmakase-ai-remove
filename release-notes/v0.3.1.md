AI Retouch 0.3.1 fixes extension startup on Ubuntu 24.04-based Linux distributions, including Zorin OS 18.

## Fixed

- **AI Local Remove can start on Ubuntu 24.04-based systems.** The Linux x86-64 package no longer requires GLIBC 2.43. Thanks to the reporter of [RAWmakase #1118](https://github.com/pch/rawmakase/issues/1118) for the diagnostic log.

Update AI Retouch in RAWmakase’s extension preferences. The Linux packages target GLIBC 2.39 or newer. This release does not change the model or saved edits.
